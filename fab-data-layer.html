STEP 1 / 5 光刻 Lithography (Bay 01)
当前步数据流向 · Lot Step Data Breakdown Bay 01
1. 本步产生什么数据 / Data Generated
光刻机曝光能量、焦面偏置、剂量配方编号及掩模版对准校准 Trace 数据（示意）。
2. 本步走什么协议 / Protocol & Ingestion
经连接层上送：SECS/GEM S6F11 站内事件流与 EDA Interface A 曝光聚焦矩阵 Trace（示意）。
3. 本步数据被谁消费 / Data Consumer
MES 执行层记录进出站与工单扣减；分析层 APC 消费焦面数据用于下一批次前馈计算（示意）。
4. 本步若数据缺失会怎样 / If Data Missing
下一步无法有把握地派工；光刻关键尺寸 (CD) 漂移无法被前馈补偿，可能引发整批线宽超差（示意）。
