为什么半导体制造需要开放倡议？

芯片设计已迎来 RISC-V 与 OpenROAD 的开源浪潮，而晶圆制造（Fab Manufacturing）仍受困于三大结构性困境：

1. 专有巨头垄断与高昂门槛

商业 Fab 工业软件（Applied SmartFactory、Siemens Opcenter、KLA Klarity 等）单厂软件授权费高达数千万美元，且各厂商协议互相封闭，形成极其顽固的数据孤岛。

2. 高校与科研人才严重断层

微电子与智能制造专业学生无法在实验室接触真实的 300mm 产线系统。缺乏脱敏开放的虚拟仿真沙盒，导致产业界长期面临懂制造、懂算法的复合型人才荒。

3. 缺乏开源参考基准（Benchmarks）

AI 算法学者想要做 FDC 故障诊断、天车调度优化或良率溯源，却根本找不到一份公开合规、物理自洽的先进制程基准数据包。开放倡议将建立首个“黄金参考基准”。

THE SIX FOUNDATIONAL PILLARS

数字孪生全栈 6 大核心支柱

一个真正的晶圆厂数字孪生，绝不仅仅是 3D 展厅，而是贯通“几何空间、调度运筹、工业通讯、工艺物理、流式数据、开源生态”的完整技术体系。

01

物理与几何空间孪生 (Physical & CAD Spatial Twin)

将传统单一的长方体白模，升华为符合 SEMI E72 占地标准与 BIM LOD300 规范的高保真物理模型体系。精细化还原机台内部结构、洁净室微环境与地下 Subfab 动力管廊。

机台内部机构解构 (Modular Anatomy) 细化 EFEM 前端微环境仓、Load Port 晶圆盒装载口、真空传输室(VTC)机械臂、多腔体(Cluster Chambers)法兰与观察视窗。
Subfab 地下动力层与管线拓扑 还原 Edwards 干式真空泵、SMC 冷水机、减排洗涤塔(Scrubber)，构建 UPW 纯水、特气、真空与酸碱排气的色标路由管网。
ISO Class 1/3 洁净室微环境 吊顶 1200×600mm FFU 阵列、0.45m/s 垂直层流沉降风速场、微穿孔防静电地板(Perforated Tiles)、微正压梯度控制。
黄光微影区光学特征 防紫外线琥珀色纯黄色滤光区（589nm 波长），防光刻胶意外曝光的专属隔离空间。
// 几何与空间规范指标
外形标准:SEMI E72 Equipment Footprint
模型格式:glTF 2.0 / USD / IFC BIM
精细度级别:LOD0 (规划) ~ LOD300 (设备结构)
动力管线色标:SEMI S2 / NFPA 79 Facility Standard
渲染引擎:Three.js (Web) / WebGPU
02

制造执行与物流离散仿真 (MES & AMHS DES Engine)

真正的半导体制造是极度重入式（Re-entrant）的超级物流系统。基于离散事件仿真（Discrete Event Simulation - DES）驱动晶圆批次（FOUP 25片/批）在全厂数百台机台间穿梭流转。

800+ 工步重入式路由树 (Routing) 光刻、刻蚀、注入、沉积、CMP 循环往复，精确模拟每道工序对同一机台的重复访问与等待。
苛刻的 Q-Time 超时管控 清洗到生长薄膜严格限制在 2~4 小时内，超时导致自然氧化或分子污染报废，模型支持动态优先级插队。
AMHS OHT 天车防碰撞与防死锁 基于时空网络流算法（Time-Space Network Flow）计算空中天车路由，防止环路死锁与干线堵塞。
Stocker 晶圆立体仓与派工算法 支持 Google OR-Tools 求解派工规则（FIFO, SPT, Critical Ratio），优化全厂瓶颈工序 OEE。
// 制造执行与物流技术选型
离散仿真内核:SimPy / Salabim (Python) / Rust-DES
运筹优化器:Google OR-Tools / OptaPlanner
载具标准:SEMI E87 CMS / SEMI E40 PJM
商业替代标杆:Siemens Tecnomatix / FlexSim / Muratec
时间同步:Discrete-Event Virtual Clock Engine
03

工业通信与虚拟设备层 (Connectivity & Virtual GEM300)

实现完整的 SEMI 300mm 工业通讯标准。提供完全开放的“虚拟设备服务端（Virtual Tool Simulators）”，无需实体机台即可完整体验与调试 MES 指令下发、状态上报与报警机制。

完整 GEM300 标准族实现 SEMI E40 (工艺作业)、E87 (载具与LoadPort握手)、E90 (单片基板跟踪)、E94 (控制作业管理)。
高频 EDA / Interface A 数据通路 基于 SEMI E157/E164 标准，建立独立于日常 MES 控制链路的数百赫兹传感器采集通道。
开放虚拟机台仿真器 (Virtual Tool) 支持双向 S1F1 握手、S2F41 远程命令、S6F11 事件上报，内置 SEMI E10 状态机（Run/Idle/Down/PM）。
OPC UA 与工业网关适配 集成 open62541 与 Eclipse Milo，实现设备底座与现代物联网工业总线的无缝转换。
// 工业通信技术协议栈
通讯底层:HSMS (SEMI E37) / SECS-II (E5)
通用模型:GEM (SEMI E30) / GEM300
开源协议库:secsgem (Python) / Open-SECS
商业替代标杆:PEER Group / Cimetrix CIM300
状态定义:SEMI E10 RAM (Reliability, Availability)
04

工艺物理与良率工程引擎 (Process Physics & YMS Engine)

良率（Yield）是晶圆厂的生命线。从简单的宏观经验公式，迈向紧凑物理代理模型（Surrogate Physics）、工业级 STDF/KLARF 数据解析与时空缺陷共性根因溯源（RCA）。

紧凑物理代理模型 (Physics Metamodels) 刻蚀与薄膜片内不均匀性 (WIWNU)、腔体季化老化漂移 (Seasoning Drift)、光刻套刻误差 (Overlay) 模型。
STDF V4 与 KLARF 工业流解析 并行解析 ATE 自动测试机台标准测试数据流，提取 Bin Map 与数万颗测试晶粒的电学参数。
共性分析与根因溯源 (Commonality RCA) 对产生环状(Ring)或局部聚集缺陷的晶圆批次，逆向检索其共同途经的机台与腔体号。
缺陷空间减法 (Defect Adder) 对比前后道暗场光学缺陷检测图，滤除已有缺陷，精确计算当前机台引入的新增颗粒。
// 良率与工艺工程技术方案
测试数据标准:SEMI STDF V4 / STDF-V4-Spec
开源解析器:PySTDF (Python) / rust-stdf (Rust)
缺陷基准数据集:WM-811K (811,472 Wafers)
商业替代标杆:KLA Klarity / PDF Solutions Exensio
良率理论模型:Poisson / Murphy / Seeds Negative Binomial
05

实时工业数据底座架构 (Industrial High-Throughput Data Fabric)

300mm 晶圆厂每日产生数以 TB 计的高频时序与缺陷数据。必须摆脱单机关系型数据库局限，采用现代“消息流 + 时序库 + 列式分析”的高通量工业混合数仓架构。

毫秒级工业消息总线 (Event Bus) 基于 Apache Kafka 或 MQTT，吞吐全厂数万点位 S6F11 事件、机台状态变更与 OHT 天车站网坐标。
时序数据存储 (Time-Series DB) TimescaleDB / InfluxDB 存储腔体高频射频功率、气体流量(MFC)、静电吸盘温度与真空度工步曲线。
高通量列式分析 (OLAP Engine) ClickHouse / DuckDB 实现亿级晶圆芯片参数测试点跨批次秒级聚合与多维钻取。
实时 SPC 与 Nelson 规则引擎 流式计算 Cp/Cpk 能力指数与休哈特控制图，毫秒级触发异常报警并推送机台联锁。
// 工业数据中枢架构栈
消息流总线:Apache Kafka / Eclipse Mosquitto
时序遥测库:TimescaleDB / InfluxDB
OLAP 列式库:ClickHouse / DuckDB
SPC 算法库:pyspc / spc-kit (SQL) / mfgQC
可视化大屏:Grafana / Apache Superset
06

开放倡议生态与数据治理 (Open Ecosystem & Benchmarks)

倡议之所以能够长久，核心在于建立开源开放的标准、合规安全的数据边界与可复现的评测基准，让全球半导体科研机构与工业界共同受益。

开放 28nm 参考制程包 (Open Benchmark) 提供自洽、脱敏的完整 300mm 流程配置（包含机台清单、标准工步、Q-Time 参数与参考良率）。
单键运行的本地沙箱 (One-Click Sandbox) 基于 Docker-Compose 提供完整测试环境：前端看板 + 虚拟 MES + 模拟器机台 + 时序数据库。
插件化接入规范 (Open Fab Plugin API) 基于 gRPC / REST 定义清晰的机台模型扩展插槽、FDC 异常算法插槽与 AMHS 调度求解器插槽。
学术与工业脱敏治理规范 严格遵守知识产权与 OEM 商业机密规范，使用参数化合成数据确保工程合法合规。

PHASE 1 IMPLEMENTATION STRATEGY

Phase 1 实施策略：极致的“形态高拟真”

在第一阶段，我们不求真正的复杂离散调度和真实网络协议通信，而是聚焦于“外表模块完整、细节严谨逼真、第一眼无可挑剔”。 如何以最低的算力与研发成本，达成顶级半导体专家一眼认可的专业级工业质感？

1. 机台工业特征模块解构

告别单调长方体白模。通过轻量参数化组件，拼装出半导体设备的典型工业解构：

  • EFEM 微环境仓：半透明防静电观察窗与 SCARA 机械臂
  • Load Ports：2~4 个倾斜装载站台，带定位销与三色灯
  • Cluster Tool：中央真空传输室与 4~6 个圆柱形反应腔
  • 附件细节：顶部排风法兰、悬臂操作屏与 SEMI E10 塔灯
成本：极低（纯前端几何拼接） · 拟真度：跃升

2. 洁净室空间质感与立体层级

营造半导体无尘车间标志性的空间氛围与纵深层次：

  • 微孔防静电地板：棋盘式 30% 开孔率通风板与下沉缝隙
  • 天花 FFU 阵列：满布规整百叶滤网与冷白高流明无影照明
  • 黄光区琥珀氛围：光刻 Bay 特有的 589nm 金黄琥珀色光晕
  • Subfab 工业色标管廊：纯水蓝、特气橙、真空灰排布
空间感：沉浸式 · 辨识度：极高

3. 机械传动“假动作”拟真

即便没有后台调度算法，用纯前端时间轴编排具有说服力的机械动作：

  • 天车取放动作：天车停稳 $\rightarrow$ 抓手垂直吊索下落 $\rightarrow$ FOUP 放置
  • 机械臂出入片：Load Port 开启，机械手夹持 300mm 晶圆送入腔体
  • 腔体发光：刻蚀腔视窗亮起淡紫色等离子体辉光(Plasma Glow)
  • 塔灯呼吸：绿色工作恒亮，蓝色等待闪烁，黄色换批呼吸
视觉信服力：顶级 · 观看体验：生动

4. “物理自洽”的伪遥测面板

不接真实机台，但面板上的波形完全符合半导体制造物理特性：

  • 刻蚀 RF 曲线：抽真空陡降 $\rightarrow$ 辉光点火峰值 $\rightarrow$ 终点(EPD)阶跃
  • 温度热滞后：静电吸盘(Chuck)控温呈现经典的一阶惯性响应
  • 休哈特控制图：严格呈现 UCL/LCL 边界与偶尔触发的 Nelson 准则点
  • SEMI E10 OEE：按运行比率实时滚动的 PR / Standby / Down 百分比
专家审视：无破绽 · 工业严谨感：拉满

Phase 1 的核心价值：以轻资产打动产业与学术界 Zero Heavy Backend

先通过极致的“外在皮相与工业模块完整度”建立视觉认同与行业声量，让所有人直观看到数字孪生落地的最终图景；再在 Phase 2/3 中逐步填入真实的离散事件仿真（DES）与 GEM300 工业内核，步步为营。
